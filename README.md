# 私密聊天室

纯静态网页（GitHub Pages）+ Supabase 免费数据库。消息、图片、名字、聊天室名称都在浏览器里用 AES-256-GCM 加密后才上传，服务器和 GitHub 只能看到密文。

## 部署 / 升级
1. Supabase → SQL Editor：运行 `supabase.sql`（可重复运行；从旧版升级不会删除数据）。
2. `config.js` 填 Project URL 和 anon / publishable key（不要用 service_role / secret key）。
3. GitHub 仓库 Settings → Pages → Deploy from a branch → `main` / `(root)`。

## 功能
- 多个聊天室：任何人都能新建；顶部 ☰ 切换、新建、粘贴邀请链接加入。
- 邀请链接 `…/#k=密钥`：点开即可看到聊天内容；第一次进入分配随机名字，可改。
- 名字、聊天室名称都可在 ⚙ 设置里修改（聊天室名称对所有人生效，并有提示）。
- 消息 “⋯” 菜单：复制、撤回（自己在本设备发的，所有人都看不到）、删除（只从本设备删除）。
- 图片：选择、粘贴或拖入后先预览再发送；自动压缩并去除 EXIF/GPS 信息。
- 在线人数 + IP：顶部显示在线人数，点开看每台设备的名字和 IP（服务器识别，不可伪造；离线 10 分钟后自动删除）；每条消息显示发送者当时的 IP（加密保存）；有新设备上线时顶部会提示。
- 存储：设置里可选消息保留 永久 / 1 / 7 / 30 / 90 天 / 1 年，过期自动删除；可查看占用；可清空聊天室。
- 可选桌面通知（只提示“有新消息”，不显示内容）。

## 须知
- 邀请链接就是钥匙：泄露 = 记录可被看到。有链接的人都能改名、设保留期、清空记录。
- 撤回只能在发送消息的那台设备上进行（清除浏览器数据后也无法撤回之前的消息）。
- 服务器能看到：各聊天室的消息数量/时间/大小、保留天数、在线设备及其 IP（只保留到离线后 10 分钟）；看不到内容和名字。
- 使用 VPN/代理时显示的是代理的 IP；手机网络 IP 会经常变化。
- 存储估算：Supabase 免费版 500MB，文字几乎不占空间，一张图片约 0.2–0.6MB。
- 页面打开时每约 3 秒同步消息、15 秒更新在线状态；没有手机推送。
- Supabase 免费项目一周无访问会暂停，控制台点 Restore 恢复。
