# 私密聊天室

纯静态网页（GitHub Pages）+ Supabase 免费数据库。消息和图片在浏览器里用 AES-256-GCM 加密后才上传，服务器和 GitHub 都只能看到密文。

## 部署
1. Supabase：新建项目 → SQL Editor 运行 `supabase.sql` → 把 Project URL 和 anon/publishable key 填进 `config.js`（不要用 service_role / secret key）。
2. GitHub：仓库 Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。

## 使用
1. 打开网址，点“我要创建一个新的聊天室” → 创建新聊天室，会弹出专属邀请链接（形如 `.../#k=随机密钥`）。
2. 把邀请链接私下发给朋友（不要发在可能被审查的地方）。
3. 朋友点开链接即可直接看到聊天内容；第一次进入会分配一个随机名字（如 `用户-7F3A`），可改成自己的名字后点“加入聊天”。点右上角名字可随时改名。
4. 打开过一次链接后，该设备再访问网址会自动进入；点“退出”则清除本机密钥。
5. 支持文字、图片（选择或直接粘贴），图片自动压缩并去除 EXIF/GPS 信息。

## 须知
- 邀请链接就是唯一的钥匙：泄露 = 所有聊天记录可被看到；所有设备都退出且没人保存链接 = 记录无法找回。
- 链接 `#` 后面的密钥不会发送给 GitHub 或 Supabase；服务器只能看到某聊天室在什么时间有多少条消息，看不到内容和名字。
- 名字只是显示用，不是账号，有链接的人可以起任意名字。
- 页面打开时每约 3 秒自动拉取新消息，没有手机推送通知。
- Supabase 免费项目一周没人访问会暂停，到控制台点 Restore 即可恢复；免费数据库 500MB。
- 国内访问 github.io / supabase.co 可能不稳定。
